# Security

Please report security vulnerabilities privately through GitHub's private vulnerability reporting:
open the **Security** tab of this repository and choose **Report a vulnerability**.
Do not open a public issue for a vulnerability.

Include the MAD version, what an attacker could do, and the steps to reproduce it.
Do not include real tokens, API keys or private code.

## 安全性漏洞回報

請用 GitHub 的私下漏洞回報功能：打開這個 repo 的 **Security** 分頁，選 **Report a vulnerability**。
請不要用公開的 issue 回報漏洞。

請附上 MAD 版本、攻擊者可以做到什麼，以及重現步驟。不要附上真實的 token、API Key 或私有程式碼。
