# MAD 0.1.0

The first free release of MAD for Windows.

## What it does

- **One conversation.** Tell the brain (Claude Code or Codex) what you want. It reads the project, asks when something is unclear, and answers directly or proposes a plan of phases and tasks.
- **Routing rules.** Your rules decide which agent gets each task. Every task shows the rule it matched, why, and its fallback. The rules page can simulate routing without calling an agent.
- **Isolated work.** Each writable task runs in its own git worktree. MAD never stashes, resets or checks out your working directory.
- **Verification commands.** Approve commands such as `npm run test`, try them first, and let tasks run them. A task that passes all its checks and needs no review is accepted for you; a task that fails gets one automatic fix.
- **Phase gates.** At the end of each phase, the gate commands run on the integrated result. The plan moves on by itself or waits for your approval; a failed gate gets one automatic fix task.
- **When quota runs out.** If a CLI reports its usage limit, MAD marks that connection as limited with the reset time and stops sending it work. You confirm a fallback agent, which continues from the previous agent's files, or let MAD retry after the reset. Rate limits and network errors are retried once.
- **Usage.** Token usage for each task and for the whole plan.
- **Restart recovery.** If MAD stops in the middle of a task, it stops the leftover CLI process on the next start, keeps the work done so far and asks you to review it.
- **Workspace.** Browse and search files, edit Markdown with a live preview, review diffs, commit, branch, push and pull, and open pull requests through `gh`.
- **Languages and themes.** English, 繁體中文 and 简体中文, with light, dark and color themes.

## Known limitations

- Windows 10 and 11, 64-bit only.
- The installer is not code-signed. SmartScreen may warn you; choose **More info**, then **Run anyway**.
- No automatic updates. Download new versions from the releases page.
- One agent works at a time.
- Codex runs through `codex exec` inside its sandbox and cannot ask for approval of single actions.
- Tested with Claude Code 2.1.316 and Codex CLI 0.166.0. Other versions may work, but their output format can change.

# MAD 0.1.0（繁體中文）

MAD Windows 版的第一個免費版本。

## 功能

- **一段對話**：告訴大腦（Claude Code 或 Codex）你想做什麼。它會先讀過專案，不清楚時先發問，再直接回答或提出分成階段與工作的計畫。
- **派工規則**：由你的規則決定每個工作交給哪個 Agent。每個工作都會標出命中的規則、派工理由與備援；規則頁可以在不呼叫 Agent 的情況下模擬派工。
- **隔離的工作環境**：每個會寫入的工作都在自己的 git worktree 執行。MAD 不會對你的工作目錄執行 stash、reset 或 checkout。
- **驗證命令**：核准 `npm run test` 這類命令、先試跑，再讓工作執行。檢查全部通過、而且不需要審查的工作會自動接受；沒通過的工作會自動修正一次。
- **階段 Gate**：每個階段結束時，在整合後的成果上執行 Gate 命令。計畫會自動往下走，或等你核准；Gate 沒通過時會自動新增一個修正工作。
- **額度用盡時**：CLI 回報用量上限時，MAD 會把那個連線標為受限、顯示重設時間，並停止派工給它。你可以確認由備援 Agent 從前一個 Agent 的成果接著做，或等額度恢復後自動重試。限流與網路錯誤會自動重試一次。
- **用量**：每個工作與整個計畫的 token 用量。
- **重啟核對**：如果 MAD 在工作進行中結束，下次啟動時會停止殘留的 CLI 程序、保留已完成的部分，並請你核對。
- **工作區**：瀏覽與搜尋檔案、編輯 Markdown 並即時預覽、查看差異、提交、分支、推送與拉取，並透過 `gh` 開 pull request。
- **語言與主題**：English、繁體中文、简体中文，以及淺色、深色與多種色彩主題。

## 已知限制

- 只支援 Windows 10 與 11（64 位元）。
- 安裝檔沒有程式碼簽章，SmartScreen 可能跳出警告；請按「其他資訊」，再按「仍要執行」。
- 不會自動更新，新版本請到版本頁下載。
- 同一時間只有一個 Agent 工作。
- Codex 透過 `codex exec` 在它的沙箱內執行，無法逐一核准單一動作。
- 已測試 Claude Code 2.1.316 與 Codex CLI 0.166.0。其他版本也許可以用，但輸出格式可能不同。
