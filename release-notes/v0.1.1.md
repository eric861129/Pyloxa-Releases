# Pyloxa 0.1.1

Easier first run, and you can now use your own API key instead of a subscription.

## What's new

- **Getting started guide.** If no agent CLI is ready, the home screen and the conversation show what to install, the official sign-in command to copy into a terminal (`claude auth login` or `codex login`), and re-detect when you come back to Pyloxa.
- **API key connections.** On the **Connections** page, switch Claude Code or Codex to your own API key. Usage is billed per use to your API account instead of your subscription. Pyloxa encrypts the key with Windows secure storage (DPAPI), passes it only to the CLI process that runs your work, and shows only the last 4 characters. Switching back to your subscription deletes the saved key.
- **Clearer connection problems.** The sidebar, the agent settings and the conversation now show the problem that actually blocks work, for example "not signed in" instead of "unverified version".
- **Re-detect finds newly installed CLIs.** Pyloxa reads PATH again when it re-detects, so you don't have to restart it after installing a CLI.
- **When the brain can't run.** A notice above the message box explains why and links to the fix. A message that couldn't be sent stays visible with the reason.

## Upgrading

Run the new installer over the old version. Your run history and projects in `%APPDATA%\Pyloxa` are kept.

## Known limitations

- Windows 10 and 11, 64-bit only.
- The installer is not code-signed. SmartScreen may warn you; choose **More info**, then **Run anyway**.
- No automatic updates. Download new versions from the releases page.
- One agent works at a time.
- Codex runs through `codex exec` inside its sandbox and cannot ask for approval of single actions.
- Tested with Claude Code 2.1.316 and Codex CLI 0.166.0. Newer versions run in supervised mode only, and their output format can change.

# Pyloxa 0.1.1（繁體中文）

第一次使用更容易上手，也可以改用自己的 API Key，不一定要訂閱。

## 新功能

- **入門引導**：沒有任何 Agent CLI 可以使用時，首頁與對話中會說明要安裝什麼，提供可以複製到終端機的官方登入指令（`claude auth login` 或 `codex login`），回到 Pyloxa 時自動重新偵測。
- **API Key 連線**：在「連線」頁可以把 Claude Code 或 Codex 改成用你自己的 API Key，用量按次計費、記在你的 API 帳單，不會用到訂閱額度。Pyloxa 以 Windows 的安全儲存（DPAPI）加密金鑰，只交給執行工作的 CLI 程序，介面只顯示最後 4 碼。改回訂閱時會刪除保存的金鑰。
- **連線問題說得更清楚**：側欄、Agent 設定與對話中，會顯示真正擋住派工的問題，例如「未登入」，而不是「版本未驗證」。
- **重新偵測找得到剛安裝的 CLI**：重新偵測時會重新讀取 PATH，安裝 CLI 之後不必重開 Pyloxa。
- **大腦不能用時**：輸入框上方會說明原因，並提供處理方式的連結；送不出去的訊息會留下原因。

## 升級

直接執行新的安裝檔覆蓋舊版即可。存在 `%APPDATA%\Pyloxa` 的執行紀錄與專案會保留。

## 已知限制

- 只支援 Windows 10 與 11（64 位元）。
- 安裝檔沒有程式碼簽章，SmartScreen 可能跳出警告；請按「其他資訊」，再按「仍要執行」。
- 不會自動更新，新版本請到版本頁下載。
- 同一時間只有一個 Agent 工作。
- Codex 透過 `codex exec` 在它的沙箱內執行，無法逐一核准單一動作。
- 已測試 Claude Code 2.1.316 與 Codex CLI 0.166.0。較新的版本只能用監督模式，輸出格式也可能不同。
