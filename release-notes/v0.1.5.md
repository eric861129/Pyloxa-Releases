# Pyloxa 0.1.5

This release adds a setup wizard for new users, lets a second agent test finished work and the brain review it, keeps Pyloxa running in the tray when you close the window, and lets you resume tasks that were interrupted. Pyloxa also has a new look that you can adjust to your taste.

## What's new

### Getting started

- **Setup wizard.** New installs start with a wizard. It explains how Pyloxa works and checks for git and Node.js. It installs the agent CLIs with their official npm commands after you confirm, then walks you through sign-in and API keys. Finally you pick the brain (Claude Code or Codex CLI), adjust who does what based on the agents you have, choose your working habits and Skills, and open a project with its verification commands. If you're upgrading, the wizard doesn't appear on its own; open it from **Settings → Setup wizard**.
- **Getting-started checklist and tips.** A checklist in the sidebar and one-time tips help the first time you meet each screen. You can turn tips off or show them again in **Settings**.
- **Versions in the wizard.** The environment check and agent install steps show the latest version, the version Pyloxa has verified, and a one-click update.

### Checking finished work

- **Brain model and effort.** Choose the brain's model and thinking effort on the **Agents** page. This doesn't change the agents that do the work.
- **Brain review.** You can have the brain review finished tasks.
  - Choose off (default), only tasks without verification commands, or all tasks.
  - The brain can accept the work, ask the same agent for one round of changes, or leave the decision to you.
  - Work it accepts is labeled as an AI review.
- **Cross-testing.** Send a finished task to a different agent to test it; for example, Codex builds and Claude Code tests.
  - The tester can only add or change test files.
  - Pyloxa reruns your verification commands itself, and their results take priority over the tester's report.
  - If the tests fail, you can send the task back to the original agent, which can't change the tester's tests.
  - Automatic cross-testing by task type or by the brain's judgment is part of the paid version, which isn't available yet.

### Running in the background

- **Keeps working when you close the window.** If work is running or scheduled, closing the window leaves Pyloxa in the system tray.
  - It notifies you when work finishes or needs you. The tray icon shows the status, with a red dot when something needs you.
  - With nothing running, closing the window quits as before. You can change this in **Settings → Background running**.
- **Quit when done.** Quitting while work is running asks first.
  - **Quit When Done** starts nothing new, waits for the running work to finish, then quits.
  - **Quit Now** stops the running work and keeps its partial changes.
- **Stays awake while working.** While work is running on AC power, Pyloxa keeps the computer from going to sleep when idle. The screen still turns off, and closing the lid or choosing Sleep still works.
  - Time limits for the brain and for verification commands count only time awake, so waking from sleep doesn't fail a run.
  - You can turn this off in **Settings → Background running**.
- **Resume interrupted tasks.** If Pyloxa quits, crashes or Windows shuts down while a task runs, you can resume it later: the same agent continues from its changes so far. After a restart, a bar at the top of the window lists interrupted tasks with **Resume All**.

### Plans and conversations

- **Compact plan cards.** Each task collapses to one line: the brain's summary and who it goes to. Details and reassignment are under **Details**.
- **Report previews.** The conversation shows each agent's report and live progress.
- **Concise replies.** A switch (off by default) asks the brain and the agents to lead with the conclusion.
- **One worktree for a whole plan.** A plan can run its tasks one after another in a single shared worktree, so installed dependencies are kept. You can switch this on the plan card before approving.
- **Fewer confirmations.** If a phase has no gate commands and you accepted each of its tasks yourself, it now passes without asking you to approve the phase.

### Gemini CLI and Skills

- **Gemini uses fewer tokens.**
  - On new installs, documentation tasks go to the brain instead of Gemini. Rules you already have aren't changed.
  - Gemini runs now compress their history earlier and can't start Gemini's built-in sub-agents.
  - In our tests with Gemini CLI 0.67.0, a one-file edit used about 56,000 tokens.
- **Gemini CLI 0.67.0 verified.**
- **Your own Skills folders.** You can add your own folders to the Skills inventory. Skills from Claude Code plugins are listed too. Both are read-only.

### Look and feel

- **A new look.** Pyloxa now uses its brand indigo by default, with a redesigned sidebar, conversation and Settings page. On Windows it has its own title bar, and on Windows 11 the window can use Mica or Acrylic.
- **Built-in fonts.** Inter, JetBrains Mono and Noto Sans TC are included, so text looks the same on every computer. You can also pick any font installed on your computer for English, Chinese and code.
- **Make it yours.** In **Settings → Appearance** you can change the accent color, interface zoom, text size, line spacing, density, corner radius, conversation width, code ligatures and animations, with a live preview.

## Privacy and safety

- Pyloxa makes no new network requests of its own. The wizard's one-click install runs the CLI's official `npm install -g` command after you confirm, which downloads from npm.
- Brain review and cross-testing are off by default. When you turn them on, each reviewed or tested task uses about one more agent run from your own subscription or API key.
- A cross-tester works in its own worktree and can change only test files: `*.test.*`, `*.spec.*`, and files in `test/`, `tests/` or `__tests__/`.
- Pyloxa doesn't start with Windows and never blocks sign-out or shutdown. Staying in the tray happens only while work is running or scheduled, unless you choose **Always stay in the tray**.
- The built-in fonts ship inside Pyloxa. Nothing is downloaded from Google Fonts or any other font service.

## Upgrading

Run the new installer over the old version. Your run history, projects, settings and saved API keys in `%APPDATA%\Pyloxa` are kept and upgraded. Your routing rules aren't changed. After upgrading, you can't go back to 0.1.4 with the same data, because 0.1.4 can't open the upgraded data folder.

The installer is about 5 MB larger than 0.1.4 because it includes the built-in fonts.

## Known limitations

- Windows 10 and 11, 64-bit only.
- The installer is not code-signed. SmartScreen may warn you; choose **More info**, then **Run anyway**.
- No automatic updates for Pyloxa itself. Pyloxa tells you when a new version is out.
- Codex runs through `codex exec` in its sandbox. On Windows, the sandbox usually can't build projects or install packages, so Codex's results are checked by your verification commands.
- Gemini CLI support is experimental. It can't act as the brain or as a cross-tester, and it can't run commands in unattended mode.
- Tested with Claude Code 2.1.318, Codex CLI 0.166.0 and Gemini CLI 0.66.0 and 0.67.0.

# Pyloxa 0.1.5（繁體中文）

這一版加入新使用者的設定精靈。完成的工作可以交給另一個 Agent 測試、交給大腦驗收。關閉視窗時 Pyloxa 會留在系統匣繼續執行，被中斷的工作也可以接續。外觀也換新了，而且可以依你的習慣調整。

## 新功能

### 開始使用

- **設定精靈**：新安裝時會先出現設定精靈。
  - 精靈會說明 Pyloxa 怎麼運作，並檢查 git 與 Node.js。
  - 你確認後，它用官方的 npm 命令安裝 Agent CLI，再帶你完成登入與金鑰。
  - 接著選大腦（Claude Code 或 Codex CLI），依你有的 Agent 調整分工，設定工作習慣與 Skills，最後開啟專案並核准驗證命令。
  - 從舊版升級不會自動出現，可以在「設定 → 設定精靈」開啟。
- **入門清單與提示**：側欄有入門清單；第一次碰到某個畫面時會出現一則提示，可以在「設定」關閉或重新顯示。
- **精靈顯示版本**：環境檢查與安裝 Agent 會顯示最新版本、Pyloxa 已驗證到的版本，並提供一鍵更新。

### 檢查完成的工作

- **大腦的模型與思考強度**：可以在「Agent」頁設定大腦的模型與思考強度，不影響執行工作的 Agent。
- **大腦驗收**：可以讓大腦驗收完成的工作。
  - 可以選關閉（預設）、只驗收沒有驗證命令的工作，或驗收所有工作。
  - 大腦可以接受、請同一個 Agent 修改一次，或交給你決定。
  - 大腦接受的工作會標示「AI 驗收」。
- **交叉測試**：完成的工作可以交給另一個 Agent 測試，例如 Codex 開發、Claude Code 測試。
  - 測試者只能新增或修改測試檔。
  - Pyloxa 會自己重跑你的驗證命令，以命令結果為準。
  - 沒通過時，可以交回原本的 Agent 修正，而且它不能改測試者寫的測試。
  - 依工作類型或由大腦判斷的自動交叉測試屬於付費版，目前還沒推出。

### 背景執行

- **關閉視窗後繼續執行**：有工作在執行或排定時，關閉視窗後 Pyloxa 會留在系統匣。
  - 工作完成或需要你處理時會通知你。系統匣圖示會顯示狀態，有事等你時帶紅點。
  - 沒有工作時，關閉視窗照常結束。可以在「設定 → 背景執行」修改。
- **做完再結束**：有工作在執行時，結束 Pyloxa 會先問你。
  - 「做完再結束」不再開始新的工作，等執行中的做完後自動結束。
  - 「立即結束」會停止執行中的工作，改到一半的內容會保留。
- **執行中不睡眠**：有工作在執行、接上電源時，Pyloxa 會讓電腦不因閒置而睡眠。螢幕照常關閉，闔上螢幕或手動睡眠也照常。
  - 大腦與驗證命令的時間上限只算醒著的時間，電腦睡醒後不會因此判定逾時。
  - 可以在「設定 → 背景執行」關閉。
- **接續中斷的工作**：Pyloxa 結束、當掉或 Windows 關機時還在執行的工作，之後可以接續，由同一個 Agent 從中斷前的成果接著做。重新開啟後，視窗頂端會列出中斷的工作，可以「全部接續」。

### 計畫與對話

- **計畫卡收合**：每個工作收合成一行，顯示大腦寫的摘要與交給誰；細節與改派放在「詳細」。
- **回報預覽**：對話中可以直接看到 Agent 的回報預覽與執行中的動態。
- **精簡回覆**：開啟這個開關（預設關閉）後，大腦與 Agent 的回覆會先講結論。
- **整個計畫共用一個 worktree**：計畫可以在同一個 worktree 依序執行所有工作，保留已安裝的依賴。核准前可以在計畫卡上切換。
- **更少的確認**：階段沒有 Gate 命令、而且工作都由你逐一接受過時，這個階段會直接通過，不用再核准。

### Gemini CLI 與 Skills

- **Gemini 用量下降**：
  - 新安裝時，文章與文件改交給大腦，不再交給 Gemini；你已有的規則不受影響。
  - Gemini 執行時會提早壓縮對話紀錄，也不能啟動 Gemini 內建的子 Agent。
  - 我們用 Gemini CLI 0.67.0 測試時，一個單檔修改用了約 5.6 萬 token。
- **Gemini CLI 0.67.0 已驗證。**
- **自訂 Skills 資料夾**：Skills 盤點可以加入你自己的資料夾，也會列出 Claude Code 外掛的 Skills，兩者都只讀。

### 外觀

- **新的外觀**：預設改用品牌的 Pyloxa 靛藍，側欄、對話與設定頁都重新設計。Windows 上改用 Pyloxa 自己的標題列，Windows 11 的視窗可以使用 Mica 或 Acrylic 材質。
- **內建字型**：內建 Inter、JetBrains Mono 與思源黑體，每台電腦看起來都一樣；英文、中文與程式碼也可以改用你電腦上已安裝的任何字型。
- **依你的習慣調整**：在「設定 → 外觀」可以調整強調色、介面縮放、字級、行距、密度、圓角、對話寬度、程式碼連字與動畫，並即時預覽。

## 隱私與安全

- Pyloxa 本身沒有增加新的網路請求。設定精靈的一鍵安裝會在你確認後，執行 CLI 官方的 `npm install -g` 命令，由 npm 下載。
- 大腦驗收與交叉測試預設關閉；開啟後，每個被驗收或測試的工作大約多用一次你自己的訂閱或 API Key 的 Agent 執行。
- 交叉測試的測試者在自己的 worktree 工作，只能修改測試檔：`*.test.*`、`*.spec.*`，以及 `test/`、`tests/`、`__tests__/` 資料夾裡的檔案。
- Pyloxa 不會隨 Windows 啟動，也不會擋住登出或關機。只有在有工作執行或排定時才會留在系統匣，除非你選「一律留在系統匣」。
- 內建字型都包含在 Pyloxa 裡，不會向 Google Fonts 或其他字型服務下載。

## 升級

直接執行新的安裝檔覆蓋舊版即可。存在 `%APPDATA%\Pyloxa` 的執行紀錄、專案、設定與保存的 API Key 都會保留並升級，你的派工規則不會被改動。升級後不能再用 0.1.4 開啟同一份資料，因為 0.1.4 無法讀取升級過的資料。

因為內建字型，安裝檔比 0.1.4 大約多 5 MB。

## 已知限制

- 只支援 Windows 10 與 11（64 位元）。
- 安裝檔沒有程式碼簽章，SmartScreen 可能跳出警告；請按「其他資訊」，再按「仍要執行」。
- Pyloxa 本身不會自動更新。有新版本時 Pyloxa 會提示你。
- Codex 透過 `codex exec` 在它的沙箱內執行。在 Windows 上，這個沙箱通常無法建置專案或安裝套件，所以 Codex 的成果以你的驗證命令驗收。
- Gemini CLI 是實驗性支援：不能擔任大腦或交叉測試的測試者，在無人值守模式下也不能執行命令。
- 已測試 Claude Code 2.1.318、Codex CLI 0.166.0，以及 Gemini CLI 0.66.0 與 0.67.0。
